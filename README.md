## Setup

To set up the project locally, follow these steps:

1. **Clone the repository**:
    ```sh
    git clone https://github.com/9enesercan/mgs-proje.git
    cd mgs-proje
    ```

2. **Install dependencies**:
    Ensure you have [Node.js](https://nodejs.org/) installed. Then, install the required dependencies:
    ```sh
    npm install
    ```

## Running the Project

To run the project locally, you can use the following commands:

1. **Start the development server**:
    ```sh
    npm run start
    ```

    This will start the project on a local server. You can view the project in your browser at `http://localhost:3000`.

2. **Build the project for production**:
    ```sh
    npm run build
    ```

    This will create a `dist` folder with the compiled project.
